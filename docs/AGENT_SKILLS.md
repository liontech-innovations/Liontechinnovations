### Installation and verification are separate from registration

Follow the [current official installation instructions](https://github.com/obra/superpowers#installation), not a copied installer or invented configuration key. Install once at the supported user/global scope for each agent environment, preserving existing plugins, skills, MCP connections and instructions. Do not vendor a second copy of the framework into each project.

| Agent | Official integration | Verification requirement |
| --- | --- | --- |
| Codex app / CLI | [Official Codex plugin marketplace](https://github.com/obra/superpowers#codex-app) | Independently confirm installed version, global scope, discovery and automatic activation in fresh sessions. Registration alone is not evidence. |
| Claude Code | [Official Claude Code plugin integration](https://github.com/obra/superpowers#claude-code) | Verify separately; a Codex installation does not install or activate Claude skills. |
| Hermes | [Official Hermes plugin integration](https://github.com/obra/superpowers#hermes-agent) | Verify separately; a Codex installation does not install or activate Hermes skills. |
| Other supported agents | [Agent-specific official instructions](https://github.com/obra/superpowers#installation) | Verify support and installation independently in each selected environment. |

No per-agent installation status is asserted by this registry. An agent without evidence must report its integration as unverified, identify the supported installation or verification step, and avoid claiming the framework is active.

For each environment, record the installed version/source, global location, discovered skills, fresh-session activation evidence, discovery outside the original directory, persistence across restart, and preservation of existing settings. Check for duplicate registration and version-specific missing skills. Back up configuration before changes; never include credentials in verification records. Keep any telemetry choice explicit and documented according to upstream's supported settings.

The central directive must be referenced through each project's or agent's supported instruction mechanism. Repository documentation neither installs plugins nor automatically propagates to unrelated repositories. Installation into Claude, Hermes or another agent requires its own authorised setup work.
