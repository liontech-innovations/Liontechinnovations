# Locked LionTech report assets

**Status:** FOUNDER APPROVED — GLOBAL STANDARD — LOCKED
**Approval date:** 16 August 2026

The blank letterhead in this directory is the canonical LionTech letterhead for future reports and company documents. The AI Visibility Snapshot template is the canonical client deliverable.

The standard report length is normally two pages, with a maximum of three pages when the evidence or action detail requires it. Reports must be substantive but not cramped: do not pad weak reports or compress strong evidence into an unreadable layout.

## Canonical page structure

### Page 1 — Snapshot overview

- Prepared-for and client details
- Report date and type
- Executive summary
- Five Gates summary
- Sampled buyer questions
- Evidence and no-guarantee note

### Page 2 — Findings and evidence

- Headline findings
- Evidence reviewed
- Tested buyer questions
- Five Gates observations
- Plain-language interpretation

### Page 3 — Priority actions and next steps

- Top five priority fixes
- Why each fix matters
- Owner and timeframe
- 30-day plan
- Quick wins
- Longer-term improvements
- Review Call, Fix Sprint and Monitoring next steps
